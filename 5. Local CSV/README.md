# Local CSV has moved to the archive

The standalone Desktop route is now at
[`archive/5. Local CSV`](../archive/5.%20Local%20CSV/README.md) and no longer receives
dashboard updates. Existing reports keep working.

New installation? Choose **[4. SharePoint](../4.%20SharePoint/README.md)**,
**[1. Fabric](../1.%20Fabric/README.md)** or **[2. Azure](../2.%20Azure/README.md)**.

Shared [samples](../shared/sample-data/README.md) and
[export/org-data helpers](../shared/scripts/README.md) remain maintained.
If you scheduled a helper from a clone, update its path to `shared\scripts`.
Existing exports and local data are not moved for you.
