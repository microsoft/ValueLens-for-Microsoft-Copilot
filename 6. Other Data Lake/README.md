# Other data lakes

ValueLens on a data lake other than Microsoft Fabric. Each route keeps the ValueLens tables and
report unchanged and swaps only where the notebooks run and where the report reads from.

[All setup choices](../README.md#choose-your-path) · [Fabric](../1.%20Fabric/README.md) · [Azure](../2.%20Azure/README.md)

| Route | What you need | Start here |
|---|---|---|
| **[Databricks](Databricks/README.md)** | A Databricks workspace with Unity Catalog and a SQL warehouse; Power BI Pro/PPU to publish | Manual setup: notebooks and a Databricks-connected Power BI template |

These routes are not installer targets. They have been checked offline only; see each route's
guide for what has not yet been verified against a live workspace.
